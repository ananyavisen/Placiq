# Placiq Mock Interviews

A separate React/Vite Mock Interviews page using the visual assets from the supplied Placiq project.

## Run

```bash
npm install
npm run dev
```

The terminal must be opened in this folder (the folder containing `package.json`).

## Visual assets reused from the supplied project

- `src/assets/bg.png`
- `public/favicon.svg`
- `public/icons.svg`

The page content is dedicated to Mock Interviews while retaining the Placiq visual language.
